# free-claude-code — מנתב מודלים (תיעוד + guardrails בלבד)

[alishahryar1/free-claude-code](https://github.com/alishahryar1/free-claude-code) (MIT) — proxy מקומי שמיירט קריאות API של Claude Code/Codex/Pi ומנתב אותן ל-25+ ספקים או מודלים מקומיים. Admin/proxy על **פורט 8082** (מקומי כברירת מחדל). Python **3.14+** + `uv`.

> **למה תיעוד בלבד (לא הוטמע כ-runtime):** מושך נגד **כלל ברזל #8** — `/scale` מצמיד `gpt-5.6-codex` (פרימיום) כברירת המחדל לבנייה; free-cc מנתב ל-מודלים חינמיים/מקומיים. בנוסף: דורש Python 3.14 (לא על הצי), מחזיק מפתחות ספקים (משטח דליפה), ומעביר קוד לצד-ג'. לכן: **אין `deploy-free-cc.sh`, אין חיווט kit-update.**

## מתי בכל זאת שימושי
עבודה **ניסיונית / חיסכון / offline / מודל מקומי** על נוד נבחר — לא production. production build נשאר על ערוצי ה-build של `/scale` (`gpt-5.6-codex` כברירת מחדל, Grok 4.6 כחלופה).

## התקנה ידנית מוקשחת (אם בחרת להקים על נוד ניסיוני)
```bash
uv python install 3.14          # free-cc דורש Python 3.14
# התקן לפי README; ואז חובה:
#  1) החלף את ה-token הדיפולטי 'freecc' ב-token אקראי חזק
#  2) bind ל-127.0.0.1 בלבד (proxy פתוח שמחזיק מפתחות = יעד לחילוץ credentials)
#  3) fcc-server להפעלה; fcc-claude/fcc-codex לניתוב הסוכנים
```

## Guardrails (אכיפה)
1. ⚠️ **הקוד שלך יוצא לספקי צד-ג'** (שמירת-דאטה חלשה ב-free tiers) — **לעולם לא על קוד רגיש**.
2. **החלף את ה-token `freecc`** מיד; **bind loopback**.
3. **משלים ולא מחליף את `/scale`** — /scale מנתב בין מודלים *פרימיום* ל-production; free-cc = ניסיוני/חיסכון/מקומי בלבד.

## Scale (כלל #8)
free-cc **הוא** מנתב — יושב **מחוץ** להצמדת ה-premium של כלל #8. אין להשתמש בו כדי לעקוף את ערוצי ה-build של `/scale` (`gpt-5.6-codex` כברירת מחדל) בעבודת production.
