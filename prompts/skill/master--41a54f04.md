# Master Orchestrator

## כללי ברזל (מחייבים!)

תשעה כללים — **אותו מספור בדיוק** כמו ב-`CLAUDE.md` של הפרויקט וב-`~/.claude/CLAUDE.md` הגלובלי
(הרשימה הזו תקציר; הנוסח המחייב שם):

1. **RTL + Responsive** - מימין לשמאל, mobile-first; רצף (1→2→3) = `flex-row-reverse`
2. **ריווח ומגע** - `gap` על ה-parent, לא `margin` על children; padding מינימלי; מגע ≥44×44px
3. **ניגודיות — תמיד** - צבעים בזוגות בלבד (`bg-x` + `text-x-foreground`), WCAG 4.5:1 — נאכף בבנייה
4. **DRY ובלי יתומים** - בדוק קיים לפני שיוצרים; `globals.css` = תוכן עניינים; מחקת אלמנט → מחק את ה-CSS שלו
5. **TypeScript Strict** - אין `any`, אין `console.log`
6. **זיכרון ומצב** - ידע → `MEMORY.md` · מצב → `PROJECT.md` · עיצוב → `DESIGN.md`, מיד ולא בסוף
7. **יכולת חדשה = 5 שלבים** - install → Skill → Agent → slash → `git push && kit-push` (`/distribute-skill`)
8. **Scale — ניתוב תלת-שכבתי, שתי אפשרויות לשכבה** - 🔵 Fable 5/Opus 5=תכנון · 🟢 Codex/Grok 4.6=ביצוע · 🟣 Opus 5/Fable 5=מורכב; העדפות ב-`~/.claude/scale-prefs`; מכריזים ולא שואלים (`/scale`)
9. **בדוק את ההנחה, לא את המימוש** - כתיבה אינה הפעלה; אמת בצד הצרכן

## Decision Trees

### Which Agent?
```
UI-only? → Design Agent
API-only? → API Agent
Auth/Security? → Security Agent
Content-only? → Content Agent
Performance? → Performance Agent
Animation? → Animation Agent
Mobile? → Mobile Agent
Automation? → n8n Agent
Multi-domain? → Fullstack Agent (or parallel)
Clone Website? → Clone Website Agent (requires claude --chrome)
Enterprise/Dual-Mode? → Ruflo Orchestrator (Claude Code + Codex + Swarm)
```

### Which MODEL tier? → /scale
```
קרא ~/.claude/scale-prefs (חסר ⇒ ברירות מחדל: תכנון=fable5 · ביצוע=codex · מורכב=opus5)
תכנון / ארכיטקטורה / חישובים? → 🔵 Fable 5 (session ראשי / Plan mode) או Opus 5 (plan-subagent)
מורכב (מיגרציה ≥3 מערכות / 2 תיקונים כושלים / >20 קבצים / אבטחה קריטית / בלתי-הפיך)?
  → 🟣 Opus 5 subagent (model: opus) או Fable 5 — רק אחרי תוכנית מה-🔵
כל השאר (השוטף, הבנייה)? → 🟢 Codex (om / codex exec — מוצמד) או Grok 4.6 (scale-env grok -p)
ערוץ נפל? → OpenRouter (codex exec --profile or / grok-or)
בתחילת משימה: הכרז על הניתוב (⚖️), אל תשאל. ספק בין שכבות? → 🟢
```

### Parallel or Sequential?
```
Tasks independent? → Parallel
Task B needs Task A output? → Sequential
Exploration/debugging? → Sequential
Implementation? → Usually Parallel
```

## Task Decomposition Patterns

### Pattern A: New Feature
```
Input: "Add user profile page"
→ Design Agent: UI components (parallel)
→ API Agent: endpoints (parallel)
→ Security Agent: permissions (parallel)
```

### Pattern B: Bug Fix
```
Input: "Login broken"
→ Explore Agent: find cause (first)
→ Relevant Agent: fix (then)
→ fs-dev Agent: add test (last)
```

### Pattern C: Performance
```
Input: "Page slow"
→ Performance Agent: profile (first)
→ API Agent: optimize queries (parallel)
→ Design Agent: optimize renders (parallel)
```

### Pattern D: Content
```
Input: "Update landing page"
→ Content Agent: Hebrew text (parallel)
→ Design Agent: layout (parallel)
```
