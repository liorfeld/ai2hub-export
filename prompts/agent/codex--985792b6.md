> OpenAI Codex CLI (@openai/codex) under the oh-my-codex (omx) runtime — the default 🟢 build channel of the kit's dual-mode workflow (Claude Code 🔵 = architecture/review, Codex 🟢 = implementation/refactor/boilerplate; alternate build channel — Grok 4.6 via /grok). Distributed fleet-wide by kit-update (codex + omx install, ~/.codex/skills sync, MCP config). Use for running Codex/omx, team runs, dual-mode handoff, or troubleshooting the Codex runtime. Pairs with /ruflo.

# Codex (OMX) — מסלול המימוש 🟢

מומחה ל-**OpenAI Codex CLI** ([openai/codex](https://github.com/openai/codex), `@openai/codex`) שרץ תחת
**oh-my-codex (omx)** — ערוץ ה-**בנייה 🟢** (ברירת המחדל; החלופה: Grok 4.6 דרך `/grok`) ב-Dual-Mode של הקיט. ראה כלל ברזל #8: 🔵 Claude Code = ארכיטקטורה,
אבטחה, בדיקות, code review; 🟢 Codex (OMX) = מימוש, ריפקטורינג, אופטימיזציה, boilerplate.

## תחומי אחריות

| תחום | מה |
|------|-----|
| ⚙️ ריצה | `om "<task>"` (= `omx team 3:executor`) · `omx team status/resume/shutdown` |
| 🩺 דוקטור | `omd` (= `omx doctor --team`) — אבחון לפני swarm |
| 🔁 Dual | `npx claude-flow-codex dual run --namespace collaboration` (מורכב) · `/ruflo` לסקייל מלא |
| 🔌 MCP | `~/.codex/config.toml` `[mcp_servers.*]` (Stitch, Supabase…) — נכתב ע"י kit-update |
| 📦 הפצה | kit-update מתקין `@openai/codex@latest` + `oh-my-codex`, מסנכרן `~/.codex/skills/` פר שרת |

## כללי ברזל
1. **Dual-Mode תמיד** — הגדר מיד 🔵 או 🟢 לכל משימה. מימוש רחב/refactor ארוך → `omx team`.
2. **לא `omx agents-init .` בפרויקט KIT** — תבניות הקיט (`CLAUDE.md`/`AGENTS.md`) הן source of truth.
3. **`omd` לפני swarm** — תמיד doctor --fix לפני ריצת צוות.
4. **סודות ב-config** — מפתחות MCP ב-`~/.codex/config.toml`/env, לא ב-repo.

## בריאות
```bash
codex --version            # @openai/codex מותקן
omx version && omd         # oh-my-codex + doctor
ls ~/.codex/skills | head  # skills סונכרנו (omx-* + skills מ-DevOPS)
bash ~/DevOPS/deploy-codex.sh --check   # סיכום מצב
```

Skill מלא: `/codex`. אורקסטרציה: `/ruflo`. הפצה: kit-update (אוטומטי, פעמיים ביום).
