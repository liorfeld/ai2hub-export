> Three-tier model-routing specialist v2 ("the perfect scale", iron-rule #8) — classifies every task to a tier and executes the handoff, honoring the sticky per-user preferences in ~/.claude/scale-prefs. 🔵 Plan = Fable 5 (claude-fable-5, default) or Opus 5 (claude-opus-5) — main session / plan-subagent; 🟢 Build = Codex (gpt-5.6-codex, pinned fleet-wide, default) or Grok 4.6 (grok-4.6 via the xAI Grok CLI) — everything else via om/codex exec or scale-env grok -p; 🟣 Complex = Opus 5 (default) or Fable 5 — subagent only, after a written plan. Announces routing at task start (asks only on genuine doubt), auto-activates on a new topic or big task, and falls back to OpenRouter (codex profiles or/grok-or) when a channel is down. Never switches the main session's model. Use to route tasks, set model preferences, escalate, or verify the pin/profiles.

# Scale v2 — הסקייל המושלם (ניתוב תלת-שכבתי, שתי אפשרויות לשכבה) ⚖️

מנתב כל משימה לשכבת המודל הנכונה לפי כלל ברזל #8 — ניתוב **per-task**, לעולם לא החלפת מודל
באמצע session. לכל שכבה שתי אפשרויות וברירת מחדל דביקה ב-`~/.claude/scale-prefs`:
🔵 Plan = Fable 5 (ברירת מחדל) / Opus 5 · 🟢 Build = Codex (ברירת מחדל) / Grok 4.6 · 🟣 Complex = Opus 5 (ברירת מחדל) / Fable 5.

## קריטריוני מורכב (🟣) — כל השאר 🟢

מיגרציה ≥3 שירותים · ארכיטקטורת אבטחה קריטית (auth/crypto/secrets/fleet-wide) · דיבוג אחרי
2 תיקונים כושלים · ריפקטור >20 קבצים עם שימור התנהגות מוכח · תכנון פעולה בלתי-הפיכה.

## כללי ברזל

1. **קרא `~/.claude/scale-prefs` לפני סיווג; הכרז, אל תשאל.** שאלה רק בספק אמיתי.
2. **ספק בין שכבות? → 🟢.** השכבה המורכבת = הסלמה, לא העדפה.
3. **🟣 רק אחרי תוכנית כתובה מה-🔵** — לעולם לא ישר למודל הכבד.
4. **אין `/model` באמצע session** — הניתוב הוא handoff/delegation בלבד.
5. **עריכה ידנית של הפין נדרסת** — override קבוע רק דרך `~/.devops-secrets`.
6. **Bootstrap לפני handoff** — `codex` חסר? `npm i -g @openai/codex@latest oh-my-codex@latest`. `grok` חסר? `npm i -g @xai-official/grok@latest`. לא מחובר (`codex login status` / אין `XAI_API_KEY`)? הדרך את המשתמש (אינטראקטיבי, חד-פעמי — אין לעקוף). עד אז: נתב לערוץ הזמין ודווח מה חסר.
