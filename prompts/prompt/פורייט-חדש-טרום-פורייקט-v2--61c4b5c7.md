## המטרה
לבצע במלואן את **כל** המשימות מה-PRD: כל מה שצריך לבנות, להכין ולבצע לפיו, וגם את כל מה שמסביב שנדרש כדי שהמוצר יעבוד באמת. זה כולל קונפיגורציה, משתני סביבה, מיגרציות, בדיקות ותיעוד הרצה.

## אם הפרויקט כולל ממשק ווב, החל את הסטנדרטים הקבועים שלי:
- עברית מלאה RTL.
- רספונסיביות לכל סוגי המכשירים.
- SEO ו-schema עם מבנה H1/H2 תקין.
- נגישות ועמודים משפטיים.
- מוכנות ל-GTM ולפיקסלים.
- תמונות WebP וביצועי PageSpeed גבוהים.
- meta theme-color בצבע המותג, favicon, ופונטים מקומיים.
- קרדיט בפוטר: " Built with 💜 by AI2U.PRO" [מתלבט פה איזה מיתוג לשים החדש או הישן וזה צריך להוביל לאתר]

## דוקר ופריסה
- עטוף את הפרויקט ב-**Docker container עם הגבלת משאבים** (CPU וזיכרון).
- הקונטיינר צריך לשרת את הפרויקט בכתובת `https://ibot.i2i.plus`, ב-HTTPS.
- תגיד לי בדיוק **איזה IP ואיזה פורט להגדיר ב-NPM** (Nginx Proxy Manager).
- **אם הדומיין `i2i.plus` מנוהל ב-Cloudflare**, במקום NPM תקים **Cloudflare Tunnel** שמותאם לקונטיינר החדש, ותן לי את כל ההגדרות שלו.
- ודא שהקונטיינר עולה, מחזיק אחרי restart ועונה בפורט שהגדרת.

## הסיכום בסוף
רק אחרי שהכול גמור, תן לי ריכוז מסודר שכולל:
1. מה נבנה ומה הסטטוס של כל משימה מה-PRD. תהיה כן לגבי מה שלא הושלם ולמה.
2. פרטי פריסה: IP ופורט ל-NPM, או הגדרות ה-CF Tunnel, ואיך מריצים ועוצרים את הקונטיינר.
3. ההחלטות שקיבלת בעצמך כשהיה חסר מידע.
4. כל השאלות, הדברים וההערות שצריכים ממני: מפתחות, סודות, DNS, אישורים וכל דבר אחר שרק אני יכול לספק.
